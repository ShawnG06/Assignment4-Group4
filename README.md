Shawn 

## Technology Stack

- Ruby
- Ruby on Rails 8.1
- PostgreSQL
- Active Record
- ERB
- Hotwire (Turbo and Stimulus)
- HTML and CSS

## Repository Structure

- `src/` — Ruby on Rails application and source code
- `dump/` — PostgreSQL database dump

## Prerequisites

- Ruby (version specified in `src/.ruby-version`)
- Bundler
- PostgreSQL
- Git

Windows developers are recommended to use WSL2 with Ubuntu.

## Initial Setup

Clone the repository:

```bash
git clone <repository-url>
cd Assignment4-Group4/src
```

Install Ruby dependencies:

```bash
bundle install
```

Verify the installation:

```bash
bundle check
bin/rails --version
```
